# SterioChat

I Used AI to Create an Advanced Roblox Custom Chat System! 🤖

I started a little experiment about: **Can someone with ZERO coding experience use AI to build a Roblox chat system with better moderation than Roblox itself?**

I know how terrible Roblox's Moderation is by fully depending on AI without human moderation, but I wanted to see and experiment if I could create a Better Roblox chat just by using AI.

With the help of AI and Roblox Lua scripting, I managed to create my own custom chat system! It includes advanced moderation, a customizable UI, stickers, emojis, player muting, saved settings, and more!

My goal with this project is simple: **to make chatting on Roblox safer and more enjoyable for everyone.** The entire project is free and open source, so anyone can try it out!

### ⚠️ Important Warning

This is still an experimental project, so please test it carefully before using it in your own game!

The chat system allows players to communicate globally without age checks or ID verification. This comes with serious risks for breaking Roblox's TOS, and may violate Roblox's communication policies, potentially putting your game or account at risk of moderation or bans or possibly a termination.

**Please make sure you understand these risks and follow Roblox's policies before using it.**
